# Privacy Log Cleaner

> **Conteúdo Educativo** - Ferramenta de estudo para remoção de logs de privacidade no Windows.

## Sobre

Ferramenta C++ para limpeza de logs de atividade do usuário no Windows, incluindo logs de execução, documentos recentes, USB e downloads.

### Objetivo Educativo
- Estudar como o Windows armazena logs de atividade
- Entender a estrutura de diretórios de logs do sistema
- Compreender técnicas de anti-forensics

### ⚠️ Aviso Importante
> Este projeto é exclusivamente para fins educacionais e de pesquisa em segurança. O código aqui presente NÃO deve ser utilizado para atividades ilegais.

## Tecnologias
- C++17
- Windows API
- STL (filesystem, chrono, regex)
